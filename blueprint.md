# Blueprint — Fleet Utilization Reports (FUR-001)

> Generated by Project Launcher Pro v4.4.1 on 7/29/2026

## Preferred / existing stack

- Next.js (App Router) + TypeScript strict
- Supabase (PostgreSQL, Auth, RLS)
- n8n for scheduled daily import
- Server-side Excel (XLSX) and PDF export
- Responsive web UI

No prior application stack in repository — preferences from Anweisungen apply (ADR-001).

## Architecture

```text
Frotcom API  -->  n8n (schedule, retry, normalize)  -->  Supabase (upsert daily reports)
                                                      ^
Manual / Excel assignment import ---------------------+
                                                      |
Dashboard (Next.js)  <---- reads history ----  Supabase
                     ---- auth/RLS -----------
                     ---- exports PDF/XLSX ---
```

Separation of duties:

| Layer | Responsibility |
|---|---|
| Frotcom | Source of vehicle activity |
| n8n | Daily orchestration, retries, alerts |
| Supabase | System of record for entities + daily reports |
| Dashboard | Filters, analysis, assignments UI, exports — **no full history re-fetch from Frotcom on page load** |

See `architecture/DECISION-REGISTER.md` and ADR-001…ADR-004.
