# Бърз старт (BG)

1. Разопаковай ZIP пакета.
2. Отвори `START HERE.html`.
3. Стартирай Launcher v4.4.1.
4. Попълни Intake / Discovery честно.
5. Експортирай проект като ZIP.
6. Отвори в Cursor: Architect → GENERATE THE PACK → Dry Run → Approval → Build.
7. Върни тестове и evidence в проектната папка.

Забележка: „Проект свързване“ изисква Chrome/Edge.
