# Architect / Builder Workflow

1. Intake & Discovery in the Launcher
2. Architect reads the repository and writes plans into the project folder
3. Human says GENERATE THE PACK only when discovery is aligned
4. Builder dry run (no edits)
5. Architect conformance review
6. Explicit human approval
7. Build → validate → Builder report → Architect review → STATE update → Git checkpoint

Architect never writes application code. Builder never edits before approval.
