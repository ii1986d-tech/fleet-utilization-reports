# Rescue Example

1. Work on a copy of the live repository when possible.
2. Choose workflow mode **rescue** and connect the folder read-only.
3. Run onboard: identity, commands, data flows, secrets, tests, contradictions.
4. Protect live behavior; no code changes until a safety-first recovery pack is approved.
5. First pack should reduce risk (baseline, observability, rollback) before feature work.
