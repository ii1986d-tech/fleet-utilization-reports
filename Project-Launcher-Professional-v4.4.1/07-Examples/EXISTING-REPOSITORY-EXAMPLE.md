# Existing Repository Example

1. Open the Launcher and choose **existing-feature** or connect the folder under Mission Control / Workspace (Chrome/Edge).
2. Scan read-only; review method files before installing updates.
3. Capture contradictions between chat claims and repository evidence.
4. Plan only the approved feature delta — do not reorganize the whole codebase.
5. GENERATE THE PACK for the smallest testable slice, then Builder dry run and approval.
