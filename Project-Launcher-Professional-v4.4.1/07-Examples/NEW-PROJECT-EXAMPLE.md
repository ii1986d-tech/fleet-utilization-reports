# New Project Example

1. Open the Launcher and choose workflow mode **new**.
2. Fill intake: name, one-liner, problem, outcome, success metrics.
3. Complete Discovery fields; leave unknowns as [OFFEN].
4. Set Gate Evidence for discovery (and business if commercial).
5. Export ZIP → open in Cursor.
6. Run Architect; only after alignment say **GENERATE THE PACK**.
7. Fresh Builder session: dry run → approval → apply → evidence.
