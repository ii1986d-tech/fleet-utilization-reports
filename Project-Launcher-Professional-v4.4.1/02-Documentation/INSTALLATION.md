# Installation

Es ist keine Installation erforderlich.

## Windows / macOS / Linux
1. ZIP entpacken.
2. `START HERE.html` oder `01-Launcher/project-launcher-professional-v4.4.1.html` in einem aktuellen Browser öffnen.
3. Für „Projekt verbinden“: **Chrome oder Edge** verwenden.

## Lokale Daten
Der Launcher speichert Zustand in `localStorage` (`project-launcher:v4.4:state`). Inkognito-Modus oder gelöschte Website-Daten verlieren den Stand. Wichtige Projekte regelmäßig als ZIP exportieren.

## Import
Nur unkomprimierte Launcher-Export-ZIPs mit `project-state.json` werden importiert. Beliebige Drittanbieter-ZIPs funktionieren nicht.
