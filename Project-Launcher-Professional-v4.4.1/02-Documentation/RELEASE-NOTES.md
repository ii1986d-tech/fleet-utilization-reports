# Release Notes — Project Launcher Professional v4.4.1

v4.4.1 ist die gehärtete Fortsetzung der Production-Edition-Verpackung aus v4.4.0.

## Was neu / behoben ist
- Kritischer Gate-Save-Bug behoben (fehlende Evidence-Editoren).
- Statusmaschine und UI Evidence-Modell wieder ausgerichtet.
- Versions- und Export-Hygiene (AGENTS, ZIP-Name, LocalStorage).
- Ehrliche Schnellstart- und Installationshinweise.

## Was unverändert gilt
- Methodik: Intake → Discovery → Pack → Dry Run → Approval → Build → Evidence → Release.
- Alles lokal im Browser; keine Cloud-Pflicht.
- Kein neues SaaS-Produkt — nur der Launcher und sein Release-Paket.

## Empfohlener Einsatz
- Neue interne Softwareprojekte
- Bestehende Repositories mit unklarem Zustand
- Rescue- und Hardening-Projekte
- Architect/Builder-Handoffs mit dokumentierter Freigabe
