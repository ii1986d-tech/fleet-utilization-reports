# How To — Architect Builder Loop (FUR-001)

> Generated by Project Launcher Pro v4.4.1 on 7/29/2026

## New project

1. Canonical SoT already materialised in repo root (ZIP-export paths).
2. Add client materials under `references/client-docs/` when available.
3. Open project root in Cursor.
4. Architect reads repository; does not write application code outside docs.
5. Say **GENERATE THE PACK** only when discovery is aligned (PACK-001 is prepared).
6. Fresh Builder session: dry run → stop → approval → apply → evidence.
7. Architect review → STATE/briefing update → Git checkpoint.
8. Repeat per sprint.

- `03-Blank-Project/architect/` or `builder/`
- `.project-launcher/` (rescue/existing only)
