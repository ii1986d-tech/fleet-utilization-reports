# ADR-003 — Auth and authorization

> Generated by Project Launcher Pro v4.4.1 on 7/29/2026

## Context

Internal tool needs admin/manager/viewer with RLS. No service-role keys in the browser.

## Alternatives

### A — Supabase Auth + RLS roles admin/manager/viewer — 86/100

Native to chosen DB stack; matches Anweisungen §16.

- Cost: 2/5
- Speed: 4/5
- Maintainability: 4/5
- Scalability: 3/5
- Risk: 2/5
- Lock-in: 3/5

### B — Custom JWT middleware in Next.js only (no RLS) — 45/100

Bypasses DB-enforced ACL; higher leak risk via misconfigured queries.

- Cost: 3/5
- Speed: 3/5
- Maintainability: 2/5
- Scalability: 2/5
- Risk: 5/5
- Lock-in: 2/5

### C — Shared password / basic auth single user — 20/100

Fails role model and audit needs.

- Cost: 1/5
- Speed: 5/5
- Maintainability: 1/5
- Scalability: 1/5
- Risk: 5/5
- Lock-in: 1/5

## Decision

Supabase Auth with RLS enforcing admin / manager / viewer.

## Rationale

Required by Anweisungen; aligns with ADR-001; single-tenant org assumed (ASM-003).
