## D1 — Transaction boundary

**One** invocation of `public.persist_assignment_import_row(...)` processes **exactly one** stored `import_job_rows` row inside **one** database transaction.

Atomic coverage (as applicable):

1. Authenticate actor (`auth.uid()`) and assert admin
2. Lock/read the import row (`FOR UPDATE` on the row)
3. Verify parent `import_jobs.status = 'confirming'`
4. Read immutable `normalized_payload` (never from client)
5. Revalidate referenced vehicle (reject missing / inactive)
6. Resolve existing driver; optionally create missing driver
7. Resolve existing customer; optionally create missing customer
8. Exact assignment duplicate recheck → **skipped** if match
9. Assignment insert (ADR-005 GiST exclusion is final overlap authority)
10. Update `import_job_rows` persistence fields + IDs + `persisted_at`
11. Preserve `validation_errors` / `validation_warnings` unchanged
12. Write `persistence_errors` for this attempt only
13. Commit and return deterministic JSON

**On any failure after master create:** entire RPC transaction rolls back — **no orphan driver/customer**, no partial row write from that invocation.

Other rows remain isolated (ADR-007 partial success).

## D2 — Binding RPC signature

```sql
public.persist_assignment_import_row(
  p_job_id uuid,
  p_import_row_id uuid,
  p_create_missing_driver boolean default false,
  p_create_missing_customer boolean default false
) returns jsonb
```

### Forbidden client inputs

Do **not** accept: assignment payloads, master IDs, normalized row contents, actor UUID, or error text from the client.

Authoritative data is read only from `public.import_job_rows` (+ related masters / assignments).

### Actor / auth

| Rule | Binding |
|---|---|
| Actor | **`auth.uid()` only** — never a client parameter |
| Null uid | Reject |
| Admin | Must pass `public.is_admin()` (or equivalent DB-safe admin assertion) **inside** the function |
| App | `requireAdmin` retained on server actions — **not** sufficient alone |
| RLS | Remains enabled; function is **SECURITY INVOKER** so RLS applies |
| Browser | Never authority |

### Security / grants

| Rule | Binding |
|---|---|
| Mode | **SECURITY INVOKER** |
| search_path | Fixed: `SET search_path = public` (or pinned safe list) |
| References | Schema-qualify `public.*` |
| PUBLIC / anon | **REVOKE ALL** — no anonymous execute |
| Grants | `EXECUTE` to `authenticated` and `service_role` only |
| Non-admin authenticated | Function raises; RLS also denies table writes |

## D3 — Canonical status vocabulary (binding)

Ambiguous mixing of ERROR / CONFLICT / INVALID / FAILED / imported across layers is **forbidden**.

### A. `validation_status` (preview; immutable after validate)

| Value | Meaning |
|---|---|
| `valid` | Row may be sent to persist RPC (includes former OK / WARNING / NEW_MASTER semantics; warnings live in `validation_warnings`) |
| `invalid` | Row must **not** invoke persist RPC (includes former ERROR / CONFLICT) |

**Apply migration** updates CHECK + backfills:

- `OK`, `WARNING`, `NEW_MASTER` → `valid`
- `ERROR`, `CONFLICT` → `invalid`

### B. `persistence_status`

| Value | Meaning |
|---|---|
| `pending` | Not yet successfully finished (includes former `not_attempted`) |
| `persisted` | Assignment inserted (replaces former `imported`) |
| `skipped` | Exact duplicate; no new insert |
| `failed` | Persist attempt failed |

**Apply migration** backfills: `imported` → `persisted`; `not_attempted` → `pending`.

### C. Stable machine error codes (minimum)

| Code | Typical use |
|---|---|
| `ASSIGNMENT_OVERLAP` | Failed row; GiST/app overlap |
| `EXACT_DUPLICATE` | Informational with **skipped** result (not failed) |
| `VEHICLE_NOT_FOUND` | Failed |
| `VEHICLE_INACTIVE` | Failed |
| `DRIVER_NOT_FOUND` | Failed when create OFF |
| `CUSTOMER_NOT_FOUND` | Failed when create OFF |
| `IMPORT_JOB_NOT_CONFIRMING` | RPC reject |
| `IMPORT_ROW_NOT_FOUND` | RPC reject |
| `IMPORT_ROW_ALREADY_PROCESSED` | Idempotent protect for persisted/skipped |
| `IMPORT_ALREADY_CONFIRMED` | Job CAS / double confirm (HTTP 409) |
| `PERSISTENCE_FAILED` | Unknown internal; safe message only |

Clarifications:

- Exact duplicate → `persistence_status = skipped` (not failed)
- Overlap → `failed` + `ASSIGNMENT_OVERLAP`
- Invalid preview rows → never call persist RPC
- No raw SQL / stack / constraint internals in return, API, audit, or report

## D4 — `persistence_errors` (mandatory)

```sql
alter table public.import_job_rows
  add column if not exists persistence_errors jsonb not null default '[]'::jsonb;
```

| Field | Rule |
|---|---|
| `validation_errors` | Preview only; **immutable** after validate |
| `validation_warnings` | Preview only; **immutable** after validate (append during validate only) |
| `persistence_errors` | Confirm-time only; array of `{code, message}` safe pairs |
| `normalized_payload` | Authoritative; **unchanged** at confirm |
| Overwrite | Persist **must not** write into `validation_errors` / `validation_warnings` |

### Retry rule for `persistence_errors`

Each new persistence attempt **replaces** the row’s `persistence_errors` with that attempt’s deterministic result.Attempt history is **out of scope** for PACK-004 (no extra history table).

### Failed-row retry (job flow)

| Rule | Binding |
|---|---|
| Initial confirm | Processes `validation_status = valid` AND `persistence_status = pending` only |
| Persisted / skipped | Final; idempotently protected (`IMPORT_ROW_ALREADY_PROCESSED`) |
| Failed rows | Remain auditable; **automatic retry out of scope** |
| Future retry | Requires a **dedicated explicit action** (not in PACK-004 Apply unless already present) |

## D7 — Job counters and completion

Counters derive from stored row states.**RPC does not finalize the whole job.**

Application confirm loop after row RPCs:

| Terminal | When |
|---|---|
| `completed` | All valid rows are `persisted` or `skipped` |
| `completed_with_errors` | ≥1 valid row `failed` |
| `failed` | Job-level failure preventing row processing (e.g. cannot load rows after CAS) |

CAS: `validated` → `confirming` only; loser → HTTP 409 `IMPORT_ALREADY_CONFIRMED`.Re-open completed → confirming: **forbidden**.

Job status `uploaded` / `parsed`: permitted in CHECK; **not required** as durable runtime steps (OQ-004-03).

## D8 — No raw SQL leakage

Row audit, API, RPC return, and Excel report must **never** store/expose raw SQL exception text, stacks, Postgres constraint internals, or Supabase transport details.

Mapper:

- Known conditions → stable code + safe message- Unknown → `PERSISTENCE_FAILED` + safe generic message- Details only in protected server logs where allowed
