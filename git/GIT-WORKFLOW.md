# Git Safety Workflow

> Generated by Project Launcher Pro v4.4.1 on 7/29/2026

- Use a private repository unless intentionally public.
- Create a clean baseline after Phase 0 docs.
- One checkpoint per accepted sprint.
- Never commit `.env`, API keys, service-role keys or client secrets.
- Record commit/revision in `BUILDER-REPORT.md` and this checkpoint.
- Keep rollback executable, not theoretical.
